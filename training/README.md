# Training material

Present `training/presentation.md` from top to bottom. It is the whole session in one file, about 45 minutes.

**The story:** one builder took IFANCA's public website, read IFANCA's mission in its own words, saw the opportunities for a new consumer experience, and built a phone app in a few hours with AI, one systematic step at a time.
